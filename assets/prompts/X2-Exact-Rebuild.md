# X2 EXACT REBUILD

Take one approved character image and rebuild it as TWO separate, same-scale, maximum-detail files (an upper pass and a lower pass) that line up perfectly in Photoshop.

## Upload
1. the approved full-body character image
2. the approved headshot, if you have one

## Paste this to run it
Run the X2 exact rebuild. Preserve the approved full-body image exactly. Do not redesign or change any visible character, pose, proportion, clothing, camera, lighting, or composition detail. Use the approved headshot only to improve supported facial, skin, eye, hair, and jewelry micro-detail in the upper pass. Generate exactly two separate same-scale maximum-detail files with approximately 10% shared overlap and matching registration crosshairs in empty white background space. Upper pass: top of hair through the overlap below the waist. Lower pass: matching overlap above the waist through complete shoes. The two files must align in Photoshop at 100% scale using translation and masking only.
