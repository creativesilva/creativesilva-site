# Slide Decks (teacher storage)

Organized master storage for the module slide decks, one subfolder per course:

- `Photography-1A/`
- `Photography-2A/`
- `Digital-Arts-1A/`

Each deck is kept as both the editable **.pptx master** (for tweaking later) and the
**.pdf** used in the modules. Filenames name the module.

**Status (2026-09-11):** these are the decks on hand, copied here for Chris to review
and finalize. The live student pages and the catalog still reference their existing
copies under `assets/course-documents/` (and `curriculum/photo2/`), so nothing is
broken. After Chris approves the finals, these become the canonical copies, the old
duplicates are removed, and both the .pptx and .pdf get posted in the teacher-facing
portal (Build Resources) for easy access.
